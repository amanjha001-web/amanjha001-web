# 🚀 Featured Project

## 🛒 ShopSphere — Multi-Vendor E-Commerce Platform

A full-stack e-commerce platform built using the MERN stack, designed to support customers, vendors and administrators.

### ✨ Key Features

- 🔐 Authentication & Authorization
- 👥 User & Role Management
- 🏪 Vendor Registration & Management
- 📦 Product & Product Variant Management
- 🛒 Cart & Wishlist
- 📋 Order Management
- 💳 Payment Integration with Razorpay
- 🎟️ Coupons & Banners
- ⭐ Product Reviews & Ratings
- 💬 Chat & Notifications
- 🔎 Product Search
- 📁 File Upload & Cloudinary Integration
- 🛡️ RBAC & Permission Management
- ⚡ Redis Integration
- 📊 Admin & Vendor Management
- 🔒 Request Validation & Security Middleware
- 📝 Logging & Error Handling
